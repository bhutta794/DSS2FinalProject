1. Overview

This report documents the implementation of a RESTful Todo Management API backend that provides authentication, public read-only todos, and authenticated CRUD operations for a user's own todo list. The solution is fully containerized using Docker.

Key Features:

  • JWT-based authentication with Bearer tokens
  • User registration and login
  • Full CRUD operations for todos
  • Pagination, filtering, sorting, and search functionality
  • Public todo access without authentication
  • PostgreSQL database persistence
  • Docker containerization
  • Swagger/OpenAPI documentation

2. How to Run Locally

Prerequisites

  • .NET 8.0 SDK
  • Docker Desktop (for PostgreSQL)

Step 1: Start PostgreSQL Database

Using Docker, run the following command:

docker run --name postgres-todo -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=todo_db -p 5432:5432 -d postgres:15

Step 2: Configure Database Connection

Ensure appsettings.json has the correct connection string:

{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Port=5432;Database=todo_db;Username=postgres;Password=postgres"
  }
}

Step 3: Run the API

Navigate to the project folder and run:

dotnet restore
dotnet build
dotnet run

Step 4: Access the API

  • API Base URL: http://localhost:3087
  • Swagger Documentation: http://localhost:3087/swagger

6. Docker Containerization

Dockerfile

FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
WORKDIR /src
COPY FinalProjectDss.csproj .
RUN dotnet restore
COPY . .
RUN dotnet publish -c Release -o /app

FROM mcr.microsoft.com/dotnet/aspnet:8.0
WORKDIR /app
COPY --from=build /app .
ENV ASPNETCORE_URLS=http://+:3087
EXPOSE 3087
ENTRYPOINT ["dotnet", "FinalProjectDss.dll"]

Docker Compose

services:
  postgres:
    image: postgres:15
    container_name: todo-postgres
    environment:
      POSTGRES_DB: todo_db
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 10s
      timeout: 5s
      retries: 5

  api:
    build: .
    container_name: todo-api
    ports:
      - "3087:3087"
    environment:
      - ASPNETCORE_URLS=http://+:3087
      - ConnectionStrings__DefaultConnection=Host=postgres;Port=5432;Database=todo_db;Username=postgres;Password=postgres
    depends_on:
      postgres:
        condition: service_healthy

volumes:
  postgres_data:

Running with Docker Compose

docker-compose up --build
